# Security and privacy

Do not post secrets, login codes, cookies, private datasets or personally identifying query history in public issues. This project never needs a personal Weibo login cookie.

If GitHub private vulnerability reporting is available for this repository, use it for confidential reports. Otherwise disclose the minimum reproducible information needed, without credentials or user data. Supported release line: 0.1 alpha; fixes are provided as capacity permits, without a response-time guarantee.

The service currently supports local stdio only. Local profiles are data namespaces, not customer authentication. Do not expose a personal unauthenticated service or share a personal database across customers. AI tools receive queried content; local storage does not mean the complete workflow is offline.
