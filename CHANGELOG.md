# Changelog

## 0.1.0a1 — 2026-10-13

- Portable Python package, CLI and seven stdio MCP tools.
- Configurable per-profile local storage, optional archiving and private POSIX files.
- Collection run provenance, deduplicated current posts and per-run snapshots.
- Source links, completeness markers, ambiguous empty-result reporting and sanitized status traces.
- Decimal-string identifiers, paced requests and a total query deadline.
- JSONL / CSV export with overwrite prevention and spreadsheet protection.
- Offline tests, CI configuration, bilingual onboarding and research templates.

Alpha release candidate. GitHub distribution is free; PyPI publication is not included. No multi-user hosting or always-on service is included.
