# 三个研究提示词模板

以下模板说明能做什么，不承诺大样本或自动代表性。请以链接、时间和批次核对引用。

## 品牌取材

请用微博研究工具搜索【品牌名】和【产品名】，各取最多10条公开样本。按问题/体验/推广/不相关分类，给出原帖链接、采集时间、run_id及正文完整性。分类是你基于帖文的判断。不要将推广帖当作独立消费者反馈，不要把这批样本称为全网舆情或总体好评率。

## 账号取材

先搜索【账号昵称】并核对UID，再读取最多15条公开动态，找出与【主题】相关的材料。说明这些材料来自账号动态样本而非完整历史；保留作者、发布日期原值、原帖链接、采集时间和run_id。身份存在歧义时先指出，不要合并同名账号。

## 跨对话继续研究

在本机已保存的微博资料中搜索【关键词】，按UID【可选】或run_id【可选】筛选，给出最多20条。区分采集时间与发表时间，不把旧存档描述成实时搜索。引用批次快照时说明正文来自当时采集；链接之后可能已变更或删除。需要新的材料再另做网络查询。
